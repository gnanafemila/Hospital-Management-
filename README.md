Hospital Management System using MySQL

About the Project

The Hospital Management System is a database project developed using MySQL to manage hospital information efficiently. It helps organize patient details, doctor information, appointments, medical records, and billing details.

Technologies Used

- MySQL
- SQL

Features

- Patient Management
- Doctor Management
- Appointment Scheduling
- Medical Records Management
- Billing Management

Database Operations

- CREATE
- INSERT
- SELECT
- UPDATE
- DELETE
- JOIN

Objective

To simplify hospital data management, reduce manual record-keeping, and maintain organized hospital information using a relational database.
